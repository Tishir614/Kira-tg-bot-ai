# KiraBot 1.8.0 — Emoji & Stability

## Для пользователей
- `/эмодзи` и `Кира эмодзи <имя>`: Kira может отправлять разрешённые Telegram custom emoji из настроенного набора.
- Это не выдаёт Telegram Premium обычным аккаунтам. Бот выступает отправителем custom emoji в пределах возможностей Telegram Bot API.
- Алкошкала теперь показывает имена участников, когда Telegram позволяет получить участника чата.
- Сохранены игровые побочные эффекты `выпить` и `дроч` из 1.7.1.

## Стабильность
- Проект уже содержит глобальный error handler, recovery runtime, service watchdog, `/status` и `/doctor`.
- Плагин custom emoji изолирован существующим plugin loader: ошибка опционального плагина не должна остановить запуск остальных модулей.
- Версия проекта поднята до 1.8.0.

## Настройка emoji
В `.env` можно добавить:
`KIRA_CUSTOM_EMOJI=лиса=1234567890123456789,сердце=9876543210987654321`
Используйте реальные custom_emoji_id, доступные вашему боту.
