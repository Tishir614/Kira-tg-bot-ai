# KiraBot 1.7.0 — Social Games & GitHub Review

- Добавлена игровая «алкошкала» 0–100: сообщение `выпить` запускает мини-сцену, результат записывается только после завершения.
- Кулдаун 1 час и защита от двойного запуска.
- `топ алкоголизм`, `топ выпивох`, `топ алкоголь`.
- Показатель намеренно игровой: это не BAC и не медицинская оценка.
- Добавлена Alembic-миграция, upgrade-скрипт сохраняет `.env` и Docker volumes.
