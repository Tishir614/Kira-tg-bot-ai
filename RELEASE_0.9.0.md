# Kira 0.9.0 — справочник и владельцы

- `/help` открывает отдельный справочник с поиском и разделами, если задан публичный HTTPS URL. Без URL остаётся встроенная справка.
- Страница `/help` обслуживается тем же веб-процессом, что и D&D, а описания берёт из общего каталога 102 slash-команды.
- Главный владелец назначает второго `@tishir22` и третьего `@Helis_pro1` по числовому Telegram ID. Их ID закрепляются в `DATA_DIR/owners.json`, поэтому смена username не передаст права другому человеку.
- `/claim_owner` в личке сообщает кандидату его ID и готовую команду для главного владельца. `/owner_bind 2 ID` и `/owner_bind 3 ID` закрепляют роли. Оба кандидата должны сначала написать боту, иначе бот не сможет им отвечать в личке.
- Совладельцы получают внутренние права владельца Киры в командах и групповой модерации. Статус Telegram-администратора группы выдаётся отдельно в Telegram.
- Исправлена защита владельцев в текстовой команде бана.

## Публикация справочника

Сайт включается без стороннего сервиса: установи `HELP_URL=https://ваш-домен/help` в сохранённом `.env`, опубликуй веб-процесс Kira через HTTPS reverse proxy на порт 8080, затем перезапусти Docker. Если уже работает D&D Mini App на `https://ваш-домен/dnd`, можно не задавать `HELP_URL`: адрес `/help` выводится автоматически. Проверь ссылку в браузере до проверки кнопки в Telegram. В исходном compose порт 8080 доступен только на сервере (`127.0.0.1`), поэтому без HTTPS reverse proxy публичная ссылка не заработает.

Это обновление сделано на базе релиза 0.8.0, сохраняя тикеты поддержки, профиль, экономику и локальный AI. Данные пользователей и `.env` сохраняет `upgrade.sh`.
