# KiraBot 1.0.1 — Русские команды и каталог

## Что изменилось
- Добавлен отдельный веб-каталог команд `/commands` в стиле крупного бот-справочника: категории, поиск и копирование команды одним нажатием.
- В Kira Mini App появилась кнопка `📚 Команды Киры`.
- Все 118 зарегистрированных slash-команд получили русские алиасы: `/память`, `/картинка`, `/дайджест`, `/профиль`, `/пред`, `/мут` и т.д.
- Английские команды **не удалены** и продолжают работать для обратной совместимости.
- Добавлен middleware, который переводит русскую команду во внутреннее старое имя до выполнения aiogram-фильтров. Сами обработчики не дублируются.
- Основной справочник и Telegram fallback-help показывают русские имена команд.
- Для новых функций 1.0 русифицированы примеры аргументов: приватность, AI-модератор, память и сводки.
- `/help` сохранён как совместимый адрес веб-справочника.
- Telegram system slash-menu использует короткие латинские транслитерации там, где Bot API не разрешает кириллицу.

## Совместимость
Старые `/memory`, `/digest`, `/image`, `/profile`, `/warn` и остальные английские команды остаются рабочими.
