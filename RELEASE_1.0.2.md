# KiraBot 1.0.2 — Nicknames & Fox Fun

## Ники

- `/ник Лис` — ник только для текущего чата.
- `/ник глобально Лис` — глобальный запасной ник.
- `/мой_ник` — посмотреть активный ник.
- `/удалить_ник` — удалить ник текущего чата.
- `/удалить_ник глобально` — удалить глобальный ник.
- Можно написать `Кира, называй меня Лис`.

Кира использует ник при естественном обращении, в AI/RP, голосовых ответах и классических RP-действиях. Старые Telegram-имена и английские команды остаются fallback-совместимыми.

## Лисий досуг

- `/правда` — вопрос для игры «Правда».
- `/действие` — безопасное смешное задание.
- `/оракул` — игровое предсказание дня; одно и то же до следующего дня.
- `/дуэль` — шуточная дуэль ответом на сообщение.
- `/комплимент` — случайный добрый комплимент себе или собеседнику.

Развлекательные команды не начисляют и не списывают монеты/XP, поэтому их нельзя использовать для фарма экономики.
