# KiraBot 0.6.4 — Подробные уведомления хозяину после обновления

- Добавлен отдельный модуль `bot/update_notifier.py`, который после каждого реального обновления пишет владельцу бота в личные сообщения.
- Сообщение начинается в стиле Киры: «Хозяин, я обновилась до …».
- В отчёте указываются создатель проекта, предыдущая версия, новая версия и идентификатор сборки.
- Кира подробно читает список изменений из файла `RELEASE_<версия>.md`; если такого файла нет, используется соответствующий раздел `CHANGELOG.md`.
- Длинные списки изменений автоматически делятся на несколько Telegram-сообщений и не упираются в лимит сообщения.
- Уведомление отправляется только `OWNER_ID`; токены, API-ключи и содержимое `.env` в текст никогда не попадают.
- Если Telegram или сеть временно недоступны, уведомление остаётся в статусе pending и повторяется после следующего перезапуска, пока не будет успешно доставлено.
- Чистая первая установка не выдаётся за обновление: для неё просто создаётся начальное состояние уведомителя.
- Старое короткое уведомление для известных чатов сохранено; владелец не получает его второй раз, потому что для `OWNER_ID` теперь используется отдельный подробный отчёт.
- Локальный AI остаётся без облачных AI API: Ollama → Qwen3 1.7B → при неудаче Llama 3.2 3B, последовательно.
- Локальные Piper TTS, локальная генерация изображений и D&D Mini App не менялись.
