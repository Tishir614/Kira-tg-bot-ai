# KiraBot 0.7.0 — Smart Dialogue & Help Center

## 🧠 Kira стала заметно осмысленнее
- Kira теперь видит текст сообщения, на которое пользователь отвечает через Telegram reply, и в личке, и в живом групповом общении.
- Короткие продолжения вроде «почему?», «а это?», «сделай так же» получают явный контекст вместо угадывания темы.
- Новый системный prompt лучше удерживает последнюю цель, исправления пользователя, имена, ограничения и многопунктовые запросы.
- `AI_SMART_DIALOGUE=1` гарантирует полезный минимум истории даже после обновления со старым `.env`.
- Увеличены дефолты памяти: 10 сообщений и 10000 символов; температура обычного диалога снижена до 0.32.
- Явно слишком короткий ответ на подробный запрос считается слабым и может переключить Kira на следующую локальную модель.

## ⚙️ Локальный AI без облачного API
- Новая цепочка для свежей установки: `qwen2.5:3b` → `qwen3:1.7b`.
- Модели запускаются строго последовательно, чтобы не держать две модели в RAM одновременно.
- `setup.sh` обновляет только старые стандартные AI-значения. Если пользователь менял модель или параметры вручную, они сохраняются.

## 📚 Новый центр помощи
- Исправлен отсутствующий обработчик `/help`.
- Все встроенные команды собраны по категориям с кратким описанием назначения.
- Командное меню Telegram сокращено до основных пунктов, а полный список находится в `/help`.
- Для администраторов автоматически показывается отдельный блок модерации.

## 💬 Админ-чат Kira
- Добавлена `/support`.
- По умолчанию `ADMIN_CHAT_URL=https://t.me/kira26481`.
- Кнопка админ-чата отображается в `/start`, `/help`, `/support` и уведомлении об обновлении.

## ✨ Внешний вид
- Стартовое сообщение стало чище и информативнее.
- Уведомление владельцу после обновления получило отдельный заголовок, визуальные разделители, блок изменений и кнопку админ-чата.
- Общая рассылка по чатам тоже получила новый стиль и кнопку админ-чата, чтобы оформление обновления было единым.
