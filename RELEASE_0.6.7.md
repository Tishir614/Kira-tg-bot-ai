# KiraBot 0.6.7 — Chat Rules Guard

Хозяин, я получила набор правил сообщества и теперь могу минимально следить за их соблюдением в группах.

## Что нового

- Добавлена команда `/rules` и текстовая команда `правила` с полным сводом правил сообщества.
- Контроль правил включён по умолчанию для всех групп, где работает Kira.
- Администраторы могут использовать `/rules on`, `/rules off`, `/rules status`.
- Автоматическая модерация намеренно работает в **минимальном режиме**: предупреждение выдаётся только за очевидные нарушения, чтобы снизить ложные срабатывания.
- Высокоуверенно отслеживаются:
  - прямые оскорбления и агрессивные провокации;
  - явные политические обсуждения/агитация, кроме исторического контекста;
  - публикация вероятных личных данных с явным контекстом деанона;
  - оскорбление веры/дискриминационные выпады с явным контекстом;
  - рекламные Telegram-ссылки и пересылки из каналов/групп;
  - IRL 18+ только когда это явно указано в подписи к медиа; furry/yiff не блокируется этим правилом;
  - стикер-флуд;
  - отправка 5+ отдельных файлов без группировки;
  - чрезмерно длинные RP-посты.
- Авто-предупреждения используют существующую систему `/warnings` и попадают в `/modlog`.
- При 3+ предупреждениях Kira уведомляет владельца/админ-чат для ручного решения. Автоматический бан или мут от rule-engine не выполняется.
- Команды `/warn`, `/mute`, `/kick`, `/ban` теперь требуют причину. Для мута указывается срок, для постоянного бана Kira явно пишет «бессрочно».
- При добавлении Kira в новую группу она сообщает, что минимальный контроль правил включён и предлагает `/rules`.

## Ограничения

Kira не делает скрытых предположений о намерениях людей и не пытается автоматически решать спорные случаи. Она также не может надёжно отличать IRL 18+ от furry 18+ только по пикселям без отдельной локальной vision-модели, поэтому неочевидные медиа остаются задачей администраторов и `/report`.
