# KiraBot 0.8.0 — Support, Economy & Smarter Local AI

## 🛟 Поддержка без прямого перехода в админ-чат

Кнопка **«Поддержка»** теперь запускает приватное обращение внутри Kira. Пользователь пишет вопрос следующим сообщением, а бот отправляет в `SUPPORT_CHAT_ID` карточку обращения с:

- именем и кликабельной отметкой пользователя;
- `@username`, если он есть;
- Telegram User ID и ID исходного чата;
- текстом вопроса;
- номером обращения;
- готовой подсказкой для ответа.

Фото, документы, видео, голосовые и другие поддерживаемые медиа копируются следом за карточкой. Владелец бота или администратор support-чата отвечает командой:

```text
/support_reply USER_ID текст ответа
```

Ответ приходит пользователю личным сообщением от Kira. По умолчанию назначения обращений: `SUPPORT_CHAT_ID=@kira26481`. Бот должен быть добавлен в этот чат и иметь право отправлять сообщения.

## 🧯 Исправление `/help`

Причиной поломки были аргументы команд вида `<вопрос>`, `<URL>` и похожие строки внутри Telegram HTML. Теперь названия и описания команд экранируются через `html.escape`. Дополнительно есть резервная отправка plain text, если Telegram отклонит HTML-разметку.

## 👤 Профиль и экономика

Добавлены:

- `/bio <текст>` — короткое описание профиля;
- `/wallet` — монеты, стоимость инвентаря и кулдауны заработка;
- `/work` — локальная подработка раз в час с монетами и XP;
- `/pay <сумма>` — перевод игровых монет пользователю через reply;
- `/richlist` — рейтинг монет среди активных участников текущей беседы.

Профиль теперь показывает ранг, уровень, XP, монеты, серию daily, инвентарь и био. Новые поля SQLite добавляются существующим механизмом миграции без удаления текущих данных.

## 🎲 Больше жизни в группах

- `/who [роль]` выбирает случайного активного участника.
- `/pair` собирает случайный дуэт и даёт мини-миссию.
- `/topic` подбрасывает тему или небольшое задание для чата.
- `/chatmood` показывает пульс беседы по накопленной активности.

## 🧠 Smart Local AI 2.0

Ollama runtime закреплён на стабильной версии `0.34.1`.

Для сервера с небольшой RAM основной моделью стала `qwen3.5:2b-q4_K_M`, резервной остаётся `qwen3:1.7b`. Скрипт `ai_quality.sh` на серверах с 6+ ГБ RAM может выбрать `qwen3.5:4b-q4_K_M`.

Для сложного вопроса Kira теперь может:

1. включить локальный reasoning у Qwen;
2. сформировать первый ответ с учётом истории и Telegram Reply;
3. выполнить ограниченную локальную самопроверку тем же загруженным экземпляром модели;
4. вернуть только исправленный финальный ответ, не показывая внутренние рассуждения.

`AI_LOCAL_ONLY=1` остаётся жёсткой блокировкой облачных текстовых AI-провайдеров. Модели Ollama переключаются последовательно и не должны одновременно занимать RAM.

## ⚙️ После обновления

Проверь, что в `.env` есть:

```env
SUPPORT_CHAT_ID=@kira26481
AI_LOCAL_ONLY=1
AI_PROVIDER_ORDER=ollama
AI_DELIBERATE_MODE=1
AI_REVIEW_PASS=1
```

Затем запусти `bash ai_quality.sh`, чтобы скачать выбранную локальную модель и применить quality-профиль.
