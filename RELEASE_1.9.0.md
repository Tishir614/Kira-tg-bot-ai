# KiraBot 1.9.0 — Living Kira

- Persistent playful side effects for `выпить` and `дроч`.
- `/effects`, `эффекты`, `побочки` show the current effect and remaining time.
- `/kira_life` / `жизнь киры` adds Kira mood, energy and current activity.
- Small secret/easter-egg interaction via `Кира секрет`.
- Existing 1.8 Premium/Custom Emoji, Crash Guard, economy, inventory, achievements, relationships, events and mini-games are preserved.
- SQLite auto-migration adds effect fields without deleting the existing database.
