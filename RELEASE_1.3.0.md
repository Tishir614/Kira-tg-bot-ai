# KiraBot 1.3.0

- `/трек` / `find_track`: распознавание музыки из reply-видео/аудио.
- Shazam используется для идентификации композиции без отдельного ключа.
- Chromaprint/fpcalc выполняет локальную акустическую проверку найденной версии.
- Поиск включает remix/slowed/reverb варианты.
- Точный файл отправляется только при достаточно сильном акустическом совпадении; иначе Kira сообщает, что основу нашла, но конкретный edit не подтверждён.
- Docker image включает chromaprint-tools.
